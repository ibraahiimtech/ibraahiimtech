## About my training

I'm working through a self-directed 6-month hands-on cyber security and cloud security training programme. The curriculum is structured around real UK job requirements for junior SOC engineer and cloud security analyst roles, drawn from analysis of seven live job postings.

Each module focuses on a specific SOC analyst skill, produces a working lab artifact (script, query, or detection rule), and is documented with a writeup mapped to MITRE ATT&CK. The programme runs across six phases:

- **Month 1 — Linux & Bash:** host auditing, persistence hunting, process forensics, log analysis at scale, host hardening.
- **Month 2 — Networking:** TCP/IP, protocol analysis with Wireshark and tcpdump, intrusion detection basics.
- **Month 3 — Azure foundations:** Entra ID, Conditional Access, Defender for Cloud, secure baselines.
- **Month 4 — Microsoft Sentinel & KQL:** data ingestion, analytic rules, hunting queries, workbooks, incident response.
- **Month 5 — Defender XDR & automation:** endpoint detections, ATT&CK-mapped rules, Azure Logic Apps playbooks.
- **Month 6 — IR, threat modelling, portfolio polish:** STRIDE threat modelling, vulnerability management, full incident reports, interview preparation.
